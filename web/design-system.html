ADO PR Ops design system

A Windows 11 Fluent 2 review desk: Mica behind the queue, a solid reading layer, cards for content, flyouts and dialogs above. One cyan accent is spent on selection, the primary command and focus. Severity carries its own color, and everything else stays neutral. This page renders the live style.css, so it can't drift from the app.

Surfaces and text

Layers step up in lightness. Text uses three emphasis levels plus disabled.

Accent and status

Each status pairs a foreground with a 12% tint. Severity uses --sev through .sev-* and .sl-*.

Type

Segoe UI Variable for interface text and Cascadia Mono for code, IDs and paths.
